# New repository instructions

1. Create a new empty GitHub repository.
2. Extract this ZIP locally, for example to `D:\RotateUV_AutoSeam_Repo`.
3. Double-click `PUSH_TO_NEW_GITHUB_REPO.bat`.
4. Paste the new repository HTTPS URL.
5. After push completes, open GitHub -> Actions -> **Build Windows Auto Seam Worker** -> Run workflow.
6. Download the successful artifact `RotateUV-Native-Auto-Seam-Windows`.

This method avoids browser drag/drop losing the hidden `.github` folder.
